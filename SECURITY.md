# Security Policy

## Supported version

Security reports are accepted for the current version on the default branch. This is a prototype and does not currently have a formal release or patch-support schedule.

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in a public issue. Use GitHub's **Report a vulnerability** option on this repository to contact the maintainers privately. Include affected files or endpoints, impact, and reproducible details where safe to do so.

Please allow maintainers a reasonable opportunity to investigate and coordinate a fix before public disclosure.

## Deployment warning

This prototype has no authentication or authorization and allows cross-origin requests for development. Do not expose it to untrusted networks or use it with sensitive production data without first addressing those risks.
